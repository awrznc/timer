カウントダウンタイマーのヘルプです。
ソースコードはこちら。

操作方法

Name Description
設定 後述の「クエリパラメータ」を参照。
開始 停止中のタイマーをマウスでクリック。
後述の「クエリパラメータ」でページを読み込んだタイミングに変更できます。
停止 動作中のタイマーをマウスでクリック。
初期化 ブラウザを更新。
もしくはタイマーのカウントダウンが終了してからマウスでクリック。

クエリパラメータ

タイマーに入力する情報は、URLのクエリパラメータから指定できます。

Name Description
trigger タイマー開始のタイミング。
指定できる値:
- click: タイマーをマウスでクリックしたときに開始（デフォルト）
- onload: ページを読み込んだときに開始
tasks タスク情報。
「時間-タスク名」の羅列。
例: tasks=00:00:01-Task1,00:00:02-Task2,00:00:03-Task3
